# Changelog

## 0.1.0 (unreleased)

First public skeleton.

- Wallpaper window embedded behind desktop icons (Windows 10 and 11)
- Shader, image, video, web page and plugin wallpapers
- Music library with background playback and a spectrum visualizer
- Widgets: clock, date, system, now playing, weather, countdown, notes
- Profiles with import and export
- Plugin system (widget, wallpaper, theme) with sandbox and permissions
- System tray, start with Windows, pause on full screen, battery saver
